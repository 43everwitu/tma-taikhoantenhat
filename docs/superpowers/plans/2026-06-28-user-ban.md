# User Ban Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add customer moderation statuses `active`, `shadow_banned`, and `banned`.

**Architecture:** Store moderation status on `users`, snapshot manual-review behavior on `orders`, and centralize status checks in `userModerationService`. Customer auth blocks hard-banned users, order creation snapshots shadow-ban state, and the payment poller routes snapshot manual-review orders to paid/manual handling.

**Tech Stack:** Node.js, Express, better-sqlite3 migrations, Telegraf middleware, Next admin users page, Node built-in test runner.
